# CheckTS — site

Site: **https://letsukki.github.io/checkts-site/**

Este repositório contém apenas os arquivos estáticos do site do CheckTS, na versão apresentada na Expotec de 17 de outubro de 2026. O aplicativo e o banco de dados não são publicados aqui.

O GitHub Pages publica a raiz da branch `main`. Para atualizar, gere o site no projeto original, aplique a substituição fornecida para a equipe e publique os arquivos resultantes nesta pasta. Não edite os módulos compilados para alterar o restante do site.

Os avisos das bibliotecas utilizadas estão em `THIRD-PARTY-NOTICES.txt`.
